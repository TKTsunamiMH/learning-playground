# Intro to Web Development

The browser is the runtime for most front-end work. A good web app usually combines HTML for structure, CSS for presentation, and JavaScript for interactivity.

## Core building blocks

- HTML gives us semantic structure.
- CSS controls layout, colors, spacing, and responsiveness.
- JavaScript adds events, state, and dynamic updates.

```js
const app = {
  title: 'dev-playground',
  status: 'learning',
};

console.log(`${app.title} is ${app.status}.`);
```

## Keep learning simple

Break big topics into small experiments. For example, build a single page that changes state when a button is clicked before you add routing or a backend.
