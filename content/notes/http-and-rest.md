# HTTP and REST

HTTP is the protocol behind most web APIs. It defines methods, status codes, and headers that clients and servers exchange.

## Common methods

- GET: read a resource
- POST: create a resource
- PUT: replace a resource
- DELETE: remove a resource

```bash
curl -X GET https://api.example.com/notes
```

REST is an architectural style that organizes resources around URLs with predictable patterns.
