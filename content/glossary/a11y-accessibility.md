## In short
Accessibility means building software that people with different abilities can use effectively.

## What it means for a .NET Full Stack developer
Use semantic HTML, keyboard navigation, focus management, and clear labels in frontend forms.  
APIs should return meaningful validation messages that UIs can announce and display clearly.  
Accessibility improves usability for everyone, not only screen reader users.

## Example
```html
<button aria-label="Save profile">Save</button>
```
