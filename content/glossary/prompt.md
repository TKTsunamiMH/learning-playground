## In short
A prompt is the input instruction and context you send to an AI model.

## What it means for a .NET Full Stack developer
Prompt wording strongly affects output quality, safety, and consistency.  
In .NET services, prompts are often templated and combined with user data or retrieved context.  
Prompt design should include guardrails for tone, scope, and formatting.

## Example
Scenario: “Summarize this support ticket in 3 bullet points for an engineer.”
