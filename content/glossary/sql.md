## In short
SQL is the language used to query and manage relational databases.

## What it means for a .NET Full Stack developer
Even with EF Core, SQL knowledge helps with debugging queries and tuning performance.  
You use SQL concepts for joins, filters, indexes, and data integrity.  
Most production .NET apps still depend on relational data patterns.

## Example
```sql
SELECT Id, Name FROM Users WHERE IsActive = 1;
```
