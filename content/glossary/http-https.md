## In short
HTTP is the protocol for web communication, and HTTPS is HTTP encrypted with TLS.

## What it means for a .NET Full Stack developer
APIs and browser apps should use HTTPS in all non-local environments.  
ASP.NET Core supports HTTPS redirection and secure headers.  
Protocol basics help with debugging status codes, cookies, and API calls.

## Example
```http
GET https://api.example.com/orders
```
