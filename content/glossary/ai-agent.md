## In short
An AI agent is a system that uses models plus tools/workflows to complete multi-step tasks.

## What it means for a .NET Full Stack developer
Agents can combine LLM reasoning with APIs, databases, and business rules.  
You need clear tool permissions, state handling, and error boundaries.  
In production, observability and human override paths are important.

## Example
Scenario: Agent reads a ticket, checks order status API, drafts a response, and asks for approval.
