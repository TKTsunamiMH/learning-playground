## In short
An ORM maps objects in code to rows in relational database tables.

## What it means for a .NET Full Stack developer
EF Core is the usual ORM in .NET projects.  
It speeds up common CRUD work while keeping data logic in C# models.  
For complex queries, you may combine ORM features with raw SQL.

## Example
Scenario: `Product` class maps to a `Products` table with EF Core configuration.
