## In short
Code review is a peer check of changes before merge to improve quality and shared understanding.

## What it means for a .NET Full Stack developer
Reviewers validate logic, security, tests, and maintainability across C#, SQL, and frontend code.  
Constructive comments improve solutions and spread knowledge across the team.  
Pairing reviews with CI checks provides stronger quality gates.

## Example
Scenario: Reviewer flags missing null-check and missing integration test before approving PR.
