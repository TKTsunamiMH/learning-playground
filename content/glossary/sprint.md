## In short
A sprint is a short, fixed period where a team commits to delivering selected work.

## What it means for a .NET Full Stack developer
Sprint goals guide what backend and frontend tasks you prioritize now.  
Work should be scoped to fit the sprint while still producing usable outcomes.  
Reviewing sprint outcomes helps improve estimation and collaboration.

## Example
Scenario: In one sprint, ship user profile API updates and matching frontend page.
