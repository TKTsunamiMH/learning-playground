## In short
CSR means the browser builds most of the page UI using JavaScript after loading.

## What it means for a .NET Full Stack developer
Your ASP.NET Core backend mainly provides JSON APIs while the frontend handles view rendering.  
This gives rich interactivity but can affect SEO and initial load times.  
API consistency and auth flows are key when frontend and backend are separated.

## Example
Scenario: React app fetches user data and renders the dashboard in-browser.
