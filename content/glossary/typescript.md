## In short
TypeScript is JavaScript with static type checking and better tooling support.

## What it means for a .NET Full Stack developer
TypeScript gives frontend code a model closer to C# style type safety.  
Shared API contract understanding becomes easier when response shapes are typed.  
It helps catch UI integration bugs at compile time instead of runtime.

## Example
```ts
type UserDto = { id: number; name: string };
```
