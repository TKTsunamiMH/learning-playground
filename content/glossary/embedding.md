## In short
An embedding is a numeric vector representation of text that captures semantic meaning.

## What it means for a .NET Full Stack developer
Embeddings enable semantic search and retrieval by meaning, not exact keyword matching.  
You can store vectors with source metadata and query similar items at runtime.  
This is a common building block for RAG systems in enterprise apps.

## Example
Scenario: Convert docs to embeddings, then fetch the most similar chunks to a user query.
