## In short
Kubernetes is a platform that manages containers across servers, handling scaling and availability.

## What it means for a .NET Full Stack developer
When your ASP.NET Core services grow, Kubernetes helps run multiple instances and route traffic.  
You define deployment settings in YAML and let the cluster restart failed containers.  
It is useful when you need more control than a simple single-host deployment.

## Example
```bash
kubectl get pods
```
