## In short
YAGNI means you should not build features or abstractions before they are actually needed.

## What it means for a .NET Full Stack developer
Avoid adding speculative extension points or complex framework code too early.  
Focus first on the currently required API and UI behavior.  
This keeps delivery faster and reduces maintenance burden.

## Example
Scenario: Skip a generic plugin system until there is a real second implementation need.
