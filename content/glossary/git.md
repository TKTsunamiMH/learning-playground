## In short
Git tracks file changes over time so teams can collaborate safely and restore history when needed.

## What it means for a .NET Full Stack developer
You use Git for branching, commit history, and merge workflows in backend and frontend code.  
It supports pull requests, code review, and release tagging for traceable delivery.  
Good commit hygiene helps debugging and teamwork across features.

## Example
```bash
git checkout -b feature/add-api-endpoint
```
