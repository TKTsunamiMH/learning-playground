## In short
A pull request is a proposal to merge code changes from one branch into another.

## What it means for a .NET Full Stack developer
PRs are where teammates review C#, ASP.NET Core, SQL, and frontend changes before merge.  
Automated checks from CI help block broken builds or failing tests.  
A clear PR description speeds up feedback and improves release quality.

## Example
Scenario: Open a PR from `feature/login` to `main` and wait for approvals plus passing checks.
