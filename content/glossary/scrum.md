## In short
Scrum is an Agile framework that organizes work into time-boxed sprints with specific team ceremonies.

## What it means for a .NET Full Stack developer
You participate in sprint planning, daily standups, review, and retrospective sessions.  
Work is tracked as user stories and tasks with clear acceptance criteria.  
Scrum helps align coding, testing, and deployment goals for each sprint.

## Example
Scenario: Team plans a two-week sprint for API improvements and UI bug fixes.
