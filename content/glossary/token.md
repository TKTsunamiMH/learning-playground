## In short
A token is a chunk of text a model reads or generates, used for limits and billing.

## What it means for a .NET Full Stack developer
Token counts affect response length, model context limits, and API cost.  
You may trim prompts, chunk documents, or summarize history to stay within limits.  
Monitoring token usage helps control AI feature performance and budget.

## Example
Scenario: Long chat history is summarized before the next LLM call to reduce tokens.
