## In short
ASP.NET Core is the modern .NET framework for building web APIs and web apps.

## What it means for a .NET Full Stack developer
You use it for routing, middleware, authentication, dependency injection, and API endpoints.  
It works well with EF Core, Azure deployment, and frontend apps that consume JSON APIs.  
Its cross-platform runtime makes local and cloud setups easier.

## Example
```csharp
app.MapGet("/health", () => Results.Ok("ok"));
```
