## In short
.NET is Microsoft’s platform for building applications using C#, F#, and related tools.

## What it means for a .NET Full Stack developer
You can build APIs, web apps, services, and tools with one ecosystem.  
ASP.NET Core, EF Core, and xUnit are common pieces in modern .NET projects.  
The same platform also supports cloud deployment and AI integrations.

```bash
dotnet --version
```
