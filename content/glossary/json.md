## In short
JSON is a lightweight text format for exchanging structured data.

## What it means for a .NET Full Stack developer
Most ASP.NET Core APIs send and receive JSON payloads.  
DTO design, serialization settings, and naming conventions all affect JSON contracts.  
Frontend and backend teams depend on stable JSON shapes.

## Example
```json
{ "id": 1, "name": "Ada" }
```
