## In short
Azure is Microsoft’s cloud platform for hosting apps, data, AI services, and infrastructure.

## What it means for a .NET Full Stack developer
Azure integrates naturally with .NET, ASP.NET Core, SQL, GitHub, and Entra-based authentication.  
You can deploy APIs, static frontends, and background jobs using managed services.  
It also gives monitoring, secrets, and scaling tools that support production apps.

## Example
Scenario: Deploy an ASP.NET Core API to Azure App Service and connect it to Azure SQL.
