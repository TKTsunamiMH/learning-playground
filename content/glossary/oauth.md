## In short
OAuth is a framework for delegated authorization without sharing user passwords between apps.

## What it means for a .NET Full Stack developer
You use OAuth/OpenID Connect with providers like Microsoft Entra ID or GitHub identity systems.  
ASP.NET Core has middleware and libraries for token validation and sign-in flows.  
Understanding the difference between OAuth roles and app roles avoids security confusion.

## Example
Scenario: User signs in via identity provider and receives an access token for your API.
