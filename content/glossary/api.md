## In short
An API is a defined way for software components to communicate with each other.

## What it means for a .NET Full Stack developer
You build ASP.NET Core APIs so frontend apps, mobile apps, or other services can use your data.  
Clear request/response contracts reduce integration bugs and speed up teamwork.  
Good APIs include validation, versioning strategy, and predictable error shapes.

## Example
Scenario: A React app calls `/api/orders` to load customer orders.
