## In short
MVC separates an app into Model, View, and Controller responsibilities.

## What it means for a .NET Full Stack developer
In ASP.NET Core MVC, controllers handle requests, models represent data, and views render HTML.  
This structure improves maintainability when server-rendered pages are used.  
The pattern is also useful conceptually for separating concerns in other app types.

Scenario: `ProductsController` loads model data and returns a Razor view.
