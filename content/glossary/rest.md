## In short
REST is an API style that models resources with URLs and standard HTTP methods.

## What it means for a .NET Full Stack developer
ASP.NET Core makes REST endpoint design straightforward with routing and result helpers.  
A RESTful API usually uses JSON and standard status codes for consistency.  
It helps frontend and backend teams align on predictable interaction patterns.

## Example
```http
GET /api/products/42
```
