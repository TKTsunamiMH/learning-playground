## In short
NoSQL databases store data in non-relational formats like documents, key-value pairs, or graphs.

## What it means for a .NET Full Stack developer
NoSQL can fit flexible schemas, high-scale reads, or event-heavy workloads.  
In .NET apps, you might combine SQL for core transactions and NoSQL for specialized use cases.  
Data modeling and query patterns differ from traditional relational design.

## Example
Scenario: Store user activity feed events in a document database for fast timeline reads.
