## In short
NuGet is the package manager for .NET libraries and tools.

## What it means for a .NET Full Stack developer
You use NuGet to add frameworks like EF Core, xUnit, and authentication packages.  
Package versions affect build stability and security updates.  
Locking and reviewing dependencies is part of reliable delivery.

## Example
```bash
dotnet add package Microsoft.EntityFrameworkCore.SqlServer
```
