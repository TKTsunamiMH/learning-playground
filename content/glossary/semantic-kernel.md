## In short
Semantic Kernel is a Microsoft SDK for orchestrating AI prompts, plugins, and memory in .NET apps.

## What it means for a .NET Full Stack developer
It helps structure prompt execution, tool calling, and model provider integration.  
You can compose AI workflows with typed .NET code and dependency injection patterns.  
This is useful when AI logic grows beyond a single model call.

## Example
Scenario: Use Semantic Kernel to call a weather plugin and include result in final AI response.
