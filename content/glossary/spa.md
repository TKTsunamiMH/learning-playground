## In short
An SPA loads one HTML page and updates the UI dynamically as users navigate.

## What it means for a .NET Full Stack developer
Your frontend (React, Blazor WebAssembly, etc.) calls ASP.NET Core APIs for data.  
Routing happens mostly in the browser, so API design and auth tokens become important.  
SPAs feel fast but require care for SEO and initial load performance.

## Example
Scenario: React app uses client-side routes and fetches `/api/products`.
