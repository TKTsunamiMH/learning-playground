## In short
An SDK is a bundle of tools and libraries used to build and run applications.

## What it means for a .NET Full Stack developer
The .NET SDK includes the CLI commands for creating, building, testing, and publishing projects.  
It is different from the runtime because it includes development tools, not just execution components.  
Choosing a consistent SDK version avoids CI and local environment drift.

## Example
```bash
dotnet new webapi
```
