## In short
TDD is writing tests before implementation, then coding just enough to make tests pass.

## What it means for a .NET Full Stack developer
TDD can help clarify requirements and keep your API or service design focused.  
It encourages small, incremental changes and quick feedback loops.  
Many teams use a practical blend instead of strict TDD for every feature.

## Example
Scenario: Write a failing test for an order discount rule, then implement the rule.
