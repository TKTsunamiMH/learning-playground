## In short
OOP is a programming style based on objects that combine data and behavior.

## What it means for a .NET Full Stack developer
C# uses OOP features like classes, interfaces, inheritance, and encapsulation.  
These concepts shape service design, domain models, and reusable components.  
Balanced OOP design avoids overly rigid class hierarchies.

## Example
```csharp
public class OrderService : IOrderService { }
```
