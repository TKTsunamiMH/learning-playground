## In short
Docker lets you package an app and its dependencies into a portable container image.

## What it means for a .NET Full Stack developer
You can run your ASP.NET Core API, frontend, and supporting services in consistent environments.  
A `Dockerfile` makes local setup easier and avoids “works on my machine” issues.  
Docker images are also commonly deployed to Azure and Kubernetes.

## Example
```dockerfile
FROM mcr.microsoft.com/dotnet/aspnet:8.0
```
