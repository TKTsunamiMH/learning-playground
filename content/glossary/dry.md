## In short
DRY means avoiding duplicated logic by extracting reusable code or shared abstractions.

## What it means for a .NET Full Stack developer
You may extract repeated mapping, validation, or API handling into shared services or helpers.  
In frontend and backend code, DRY can reduce maintenance costs when requirements change.  
Over-abstraction is still possible, so keep reuse practical and clear.

## Example
Scenario: Move repeated date formatting into one helper used by multiple pages.
