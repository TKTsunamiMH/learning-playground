## In short
Blazor is a .NET web UI framework for building interactive interfaces with C# instead of JavaScript for most logic.

## What it means for a .NET Full Stack developer
You can share models, validation, and tooling across frontend and backend in one .NET stack.  
Blazor supports server and WebAssembly hosting models with different tradeoffs.  
It is useful when teams prefer C# end-to-end.

## Example
```razor
<button @onclick="Save">Save</button>
```
