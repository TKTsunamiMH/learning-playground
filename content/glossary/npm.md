## In short
npm is the package manager used for JavaScript and TypeScript dependencies.

## What it means for a .NET Full Stack developer
Even in .NET projects, npm usually manages frontend build tools and libraries.  
You run scripts for dev server, linting, and production builds from `package.json`.  
Keeping lockfiles committed helps CI produce repeatable frontend builds.

## Example
```bash
npm install
```
