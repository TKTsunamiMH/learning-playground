## In short
SSR means HTML is rendered on the server before being sent to the browser.

## What it means for a .NET Full Stack developer
SSR often improves first paint and SEO compared with pure CSR.  
In .NET, this can be done with Razor Pages, MVC views, or server-rendering frameworks.  
You may combine SSR with API endpoints and client hydration for interactivity.

## Example
Scenario: Server renders product page HTML, then client JavaScript adds interactions.
